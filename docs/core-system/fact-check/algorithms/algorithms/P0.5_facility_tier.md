## Code Behavior (as implemented)

- **`normalize_facility_tier()`** (`facility_tier.py:74-127`):
  - Explicit map for synthetic + frontend tier strings (`_EXPLICIT_TIER_MAP`)
  - Prefix heuristics (`3_`, `universite`, `egitim_arastirma`)
  - Unknown → **basamak 2**, `used_default=True` (conservative: no §2.2.2(2) override)
  - University `provider_type` can upgrade unknown tier to basamak 3 + `is_university_eah`
- **`allows_section_2_2_2_override`:** true only when `basamak == 3` (`facility_tier.py:69-71`) — matches tier gate, not full override rule (star check elsewhere)
