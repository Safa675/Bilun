## Gate C — Logic diff (code vs prose)

| Condition (from SUT / EK-4A) | BILUN behavior | Match? |
|------------------------------|----------------|--------|
| Drug discounts per EK-4/A + §4.4.1 tier ladders | Heuristic path reads `discount_tier_1`, `discount_status` from catalog; does **not** compute payable from list prices | partial |
| Therapeutic equivalence / substitution | Builds `equivalence_group` index; flags `ESDEĞER` alt or tier delta > 5 pp | partial — clinical/catalog signal only |
| Passivated / non-reimbursed drugs | Skips passivated rows in index; flags patient drugs with `passivation_date` | partial — alert only |
| Monetary "recovery" from substitution | Heuristic: `generic_substitution_savings = 0.0`, `savings_try: null` on recommendations | **Y** (honest gap) |
| Exact dispensed lines | `optimize_drug_from_claims`: sums `billed − payable` per line; max(heuristic, claim delta) | **Y** for applied tiers on submitted lines |
| Pick best generic | Takes **first** matching alt in index iteration order, not minimum cost | **N** |
| Prove substitution savings in exact mode | Tier savings attributed to **same** drug line (`issue: discount_tier_applied`), not alt SKU | partial |

### Code behavior (as implemented)

- **Inputs (heuristic):** `patient_drug_names` → `lookup_drug_bulk()` → EK-4A fields (`equivalence_group`, `discount_status`, `discount_tier_1`, `passivation_date`).
- **Inputs (exact):** `PatientClaimContext.drug_lines` with `billed_amount_try`, `expected_payable_try`, `discount_tier_expected`.
- **Passivation:** `drug.py:71-87` — increment `passivated_drug_count`, recommend first active member of equiv group.
- **Generic:** `drug.py:98-127` — `ESDEĞER` status or `alt_d1 > current_d1 + 0.05`; no TRY estimate.
- **Exact savings:** `drug_claims.py:34-63` — tier delta per line; exempt patients skip tier recommendations (`is_exempt`).
- **Savings formula:** Heuristic: `0`. Exact: `max(heuristic_savings, Σ(billed − payable))` with exempt handling via `discount_from_claims` (`drug_claims.py:59-63`).
