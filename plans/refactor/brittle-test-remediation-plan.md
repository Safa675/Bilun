## Goal

Stop tests from acting as frozen censuses of data artifacts. Rewrite brittle suites so legitimate corpus / synthetic / gazette changes do not require mass assertion rewrites. Preserve real regression protection via derived counts, soft floors, and self-consistency invariants.

**Done looks like:** no standalone magic-number `len(X) == N` / `height == N` locks against live parquet/JSON/synthetic fixtures in `tests/unit`, except where N is derived in the same test from the source of truth; CI stays green across a SUT re-extract and a synthetic regen without hand-editing count literals.

---

## Design principles (copy these patterns)

### 1. Derive from source of truth (preferred)

```python
# GOOD — count comes from the same artifact the code under test reads
expected = len(json.loads(rules_path.read_text())["rules"])
assert len(loaded_rules) == expected

# GOOD — section total equals the export frame built in this test
frame = shim_export_candidates(...)
assert manifest["section_clause_total"] == frame.height
```

### 2. Soft floors for growth metrics

```python
# GOOD — catches regressions (count dropped) without blocking growth
assert len(corpus_sections) >= 179  # baseline 2026-07; see Phase 0.3
```

### 3. Self-consistency invariants (not absolute sizes)

```python
# GOOD — survives rule additions
assert set(manifest["encoded_clause_ids"]) <= rule_gate_b_sources
assert manifest["encoded_count"] == len(manifest["encoded_clause_ids"])
assert tier_a + tier_b + tier_c == frame.height
```

### 4. Scenario-tag resolution (not patient/claim ID pins)

```python
# GOOD — from demo_config / vignette_registry
patient_id = vignette_for_scenario_tag("sgk_drg_uplift_yatis").patient_id
demo_claim = _claim_by_scenario_tag(ctx, "sgk_drg_uplift_yatis")
```

### 5. What stays exact (legitimate locks)

| Keep as exact | Why |
|---------------|-----|
| `pending_untraced == 0` after repair | Real invariant — repair must clear the queue |
| Formula checks on **test-injected** Decimals | Input is owned by the test |
| Mock sentinel passthrough (`42.0` from mock → API) | Asserts wiring, not business census |
| `len(FACT_CHECK_AUDIT_UNITS) == AUDIT_TOTAL_UNITS` | Constant identity (both sides same module) |
| Golden JSON files as SoT when regenerated by a build step | File is the contract; test loads it |

### 6. What must die

| Kill | Why |
|------|-----|
| `assert frame.height == 131` against live parquet | Breaks on every re-extract |
| `assert len(rules) == 202` against live JSON | Breaks on every encode |
| `assert len(dataset.claims) == 96` against committed synthetic | Breaks on every regen |
| Hardcoded `SENTETIK-HASTA-0002` when a scenario_tag exists | Breaks on vignette reassignment |
| Live-catalog TRY prices without a fixture stub | Breaks on gazette/`katsayı` update |
| Full TR `description_tr == "…"` equality in API tests | Breaks on copy edits |

## Shared helpers to add (once, early)

Create `tests/unit/_helpers/brittle_guards.py` (or `tests/helpers/`) with:

1. **`assert_manifest_consistent(manifest, frame, *, rules=None)`**
   - `section_clause_total == frame.height`
   - count fields == list lengths
   - encoded ⊆ rule `gate_b_sources` when rules provided
   - tier partitions sum to total when `encode_tier` column present

2. **`parquet_section_count(clauses_path, prefixes) -> int`**
   - in-force rows matching GateB section prefixes

3. **`soft_floor(actual, floor, *, label)`**
   - `assert actual >= floor` with a clear failure message naming the baseline date

4. **`patient_for_scenario(tag) -> str`** / reuse `vignette_for_scenario_tag` from `demo_config`

Phases 1–2 must land helpers before bulk rewrites so each file stays thin.
