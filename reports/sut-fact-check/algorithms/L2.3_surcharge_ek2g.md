### Flag semantics (important)

On synthetic claim lines, `surcharge_applicable = (code NOT IN ek2g_no_surcharge)` (`scripts/synthetic/generators.py:392`).  
`build_exact_surcharge_exposure` counts lines where `surcharge_applicable is True` — i.e. procedures **not** on the EK-2G prohibition list (surcharge **may** be applied under SUT). This is **eligibility / exposure surface**, not a count of §1.9.3 violations.

### Code behavior (as implemented)

- **Inputs:** `SurchargeClaimContext` with dated `ProcedureClaimLine` rows (`claim_context.py:28-37`).
- **Gating:** `get_surcharge_context()` via `ContextVar` (`runtime_claim_context.py:19-20`); absent → missing inputs (`surcharge.py:16-18`).
- **Logic:** Filter applicable lines; compute `exposure_rate = len(applicable) / total` (`exactness.py:97-124`).
- **Savings formula:** None — descriptive counts only (no `savings_try`).
