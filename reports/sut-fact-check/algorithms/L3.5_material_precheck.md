## Code Behavior (as implemented)

### Partial mode — `_precheck_materials()` (`materials.py:139-171`)

- Maps ICD-10 chapter → EK-3 specialty annex ids (`_CHAPTER_TO_SPECIALTY`)
- Sets `gazette_ceiling_by_specialty[spec] = p90` price — **HEURISTIC**, not SUT rule
- Does **not** load EK-3C-1 or EK-3C-2 in this path
- Default `exactness_status` from `MaterialPreCheck` = `partial` (`types.py:142-146`)

### Exact mode — `precheck_materials_from_claims()` (`claim_materials.py:11-62`)

- Builds `preauth_codes` / `miat_codes` dicts from parquets
- Flags line if `code in preauth_codes` or `line.requires_pre_auth`
- Flags line if `code in miat_codes` — **membership only**, no date math vs prior procedures
- **Bug / conflation:** `line.is_bundled` entries appended to `miat_restricted` with note “Bundled material billed separately” (`claim_materials.py:48-57`) — wrong bucket (should be bundling / EK-3B-1)
- Note text says “sağlık kurulu” (`claim_materials.py:34`) — SUT says **tıbbi uygunluk** for EK-3C-1 (board may be one pathway, not verbatim)
