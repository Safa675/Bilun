## Code Behavior (as implemented)

- **Inputs used:** `materials[].name`, optional `unit_price`, `quantity`; `procedure_code` passed through to violation payload only
- **Inputs ignored:** SUT material codes, procedure–material pairing rules from §3.1.11 (birebir uyan işlem), care setting, EK-2B procedure annex for "included in points" flags
- **Logic:** Load EK-3B-1 index → for each material line, substring/fuzzy match → emit violation with `savings_try = unit_price × quantity`
- **Severity:** `error` if billed > 50 TRY else `warning` (`bundling_rules.py:114`)
- **Savings formula:** Full billed line amount — justified as "remove separate line before submission" **if** match is true positive
- **Citations:** `bundling_rules.py:29-100`, `exclusions.py:59-91`, `rule_engine.py:114-132`
