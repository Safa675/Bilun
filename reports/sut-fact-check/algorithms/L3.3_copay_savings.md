**Savings formula (exact, exempt):**

```
visit_savings = Σ (billed_amount_try - expected_payable_try)
  for procedure_lines where copay_rate_applicable and component > 0
rx_savings    = Σ (billed - payable) for drug_lines (informational)
total_copay_savings_try = visit_savings only
```
