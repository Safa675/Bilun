## Code Behavior (as implemented)

### Legacy path — `get_drg_package_price()` (`drg.py:135-164`)

1. Chapter keyword-filtered median if present
2. Else group median (all packages in EK-2C group)
3. Else hardcoded `_FALLBACK_GROUP_MEDIANS` / constant `7_593.09`

→ **HEURISTIC** for patient-level “what SGK pays”; suitable for cohort dashboards only.

### Dated path — `get_drg_package_price_for_date()` (`drg.py:167-187`)

- Filters packages with `effective_date <= asof_date` (`_is_effective_on_or_before`)
- Returns `None` if no eligible packages (no future-price leak) — **COMPLIANT** temporal hygiene
- Tests: `tests/unit/domain/test_pricing_temporal.py`

### Caching

- Global `_ek2c_group_medians` / `_ek2c_chapter_medians` for undated calls
- Per-date cache `_ek2c_exact_medians_by_asof`
