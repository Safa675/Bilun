## Code Behavior (as implemented)

### Catalog aggregation
- Module-level cache `_all_specialty_cache` (```17:48:src/bilun/domain/materials/specialty.py```).
- Uses `_load_ek3_materials_parquet()` per file (```266:295:src/bilun/domain/loaders/gazette.py```).

### Analytics price index
- `estimate_material_costs()` builds lowercase name → `(price, source)` index from all specialty materials (```39:45:src/bilun/domain/analytics/materials.py```).
- Lookup order: exact name → substring → fuzzy 0.80 (`fuzzy_match_name`).
- Bundling/reimbursement flags: `is_consumable_bundled()`, `is_material_reimbursable()` (EK-3B-1 / EK-3B-2 helpers).
- Hospital `unit_price` retained when catalog miss (`catalog_miss` source).
