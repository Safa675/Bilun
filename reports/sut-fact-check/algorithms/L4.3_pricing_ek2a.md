## Annex / Catalog Evidence
- **Catalog:** `data/gazette/curated/ek2a_outpatient_visits.parquet`
- **Row count:** 87 specialties (verified 2026-06-02)
- **Key fields:** `specialty_code`, `specialty_name`, `section`, 16 tier columns (`OH3`, `U1`, `U2`, `A1`, `A1_DAL`, `A2`, `A2_DAL`, `B`, `C`, `OH2`, `D`, `E`, `KTM`, `KDM`, `OTM`, `ODM`) + optional `*_note`
- **Extractor:** `scripts/sut/catalogs/simple_materials.py` → `extract_ek2a()` (```92:122:scripts/sut/catalogs/simple_materials.py```)
- **Temporal behavior:** Static snapshot; no `effective_date` column in curated parquet — **no service-date versioning** (unlike EK-2B history)

## Code Behavior (as implemented)

### Canonical loader
- `_load_ek2a()` reads parquet, builds per-specialty `prices_try` dict, caches via `get_cached_ek2a()` (```212:303:src/bilun/domain/loaders/gazette.py```).
- Public API: `get_ek2a_visit_prices()` in `catalog.py` (```307:309:src/bilun/domain/catalog.py```).

### EK-2B visit map (separate path)
- `get_visit_prices()` maps descriptive keys to **EK-2B** codes (e.g. `outpatient_visit` → `520030`) via `load_sut_catalog()["ek2b"]` (```221:249:src/bilun/domain/catalog.py```) — **not** EK-2A specialty-tier matrix.

### Runtime enrichment (heuristic)
- `_enrich_visit_prices_from_ek2a()` averages **all** tier prices across **all** specialties, sets single `outpatient` and `emergency` tuple (```69:85:src/bilun/domain/estimators.py```).
- Does not use patient specialty, facility tier, or branch section from EK-2A.
